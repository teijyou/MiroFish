## ⚡ プロジェクト概要

**MiroFish** は、マルチエージェント技術を基盤とした次世代の AI 予測エンジンです。現実世界のシード情報（速報ニュース、政策草案、金融シグナルなど）を取り込み、高忠実度の並行デジタル世界を自動構築します。この空間では、独立した人格・長期記憶・行動ロジックを持つ多数のエージェントが自由に相互作用し、社会的に進化します。ユーザーは「神の視点」で変数を動的に注入し、未来の展開を精密に推演できます。**デジタル沙盤で未来を先に演習し、数多くのシミュレーションを経て意思決定の勝率を高める**ことが可能です。

> 必要なのは、シード資料（データ分析レポートや小説のストーリーなど）をアップロードし、自然言語で予測要件を伝えるだけです。 </br>
> MiroFish が返すもの：詳細な予測レポートと、深く対話可能な高忠実度デジタル世界

### 私たちのビジョン

MiroFish は、現実を写像する群知能ミラーの実現を目指しています。個々の相互作用から生まれる集団の創発を捉えることで、従来の予測の限界を突破します。

- **マクロ視点**：意思決定者のためのリハーサル実験室として、政策や広報施策をゼロリスクで検証
- **ミクロ視点**：個人ユーザーの創造的サンドボックスとして、小説結末の推理から自由な発想実験まで、楽しく手軽に体験可能

厳密な予測から遊び心あるシミュレーションまで、あらゆる「もしも」に結果を与え、「万物予測」を現実にします。

## 🔄 ワークフロー

1. **グラフ構築**：シード抽出 & 個体／集団記憶の注入 & GraphRAG 構築
2. **環境構築**：エンティティ関係抽出 & ペルソナ生成 & エージェント設定の注入
3. **シミュレーション実行**：デュアルプラットフォーム並列実行 & 予測要件の自動解析 & 時系列記憶の動的更新
4. **レポート生成**：豊富なツール群を持つ ReportAgent がシミュレーション後環境と深く対話
5. **深いインタラクション**：シミュレーション世界の任意エージェントとの会話 & ReportAgent との対話

## 🚀 クイックスタート

### 方法1：ソースコードデプロイ（推奨）

#### 前提条件

| ツール | バージョン | 説明 | インストール確認 |
|------|---------|------|---------|
| **Node.js** | 18+ | フロントエンド実行環境（npm を含む） | `node -v` |
| **Python** | ≥3.11, ≤3.12 | バックエンド実行環境 | `python --version` |
| **uv** | 最新版 | Python パッケージマネージャー | `uv --version` |

#### 1. 環境変数を設定

```bash
# サンプル設定をコピー
cp .env.example .env

# .env を編集して必要な API キーを入力
```

**必須環境変数：**

```env
# LLM API 設定（OpenAI SDK 互換形式の任意 LLM API に対応）
# 推奨：阿里クラウド百錬の qwen-plus モデル https://bailian.console.aliyun.com/
# 消費が大きいため、最初は 40 ラウンド未満でのシミュレーション推奨
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL_NAME=qwen-plus

# Zep Cloud 設定
# 無料枠でも簡易利用には十分：https://app.getzep.com/
ZEP_API_KEY=your_zep_api_key
```

#### 2. 依存関係をインストール

```bash
# 依存関係を一括インストール（root + frontend + backend）
npm run setup:all
```

または段階的に実行：

```bash
# Node 依存をインストール（root + frontend）
npm run setup

# Python 依存をインストール（backend、仮想環境を自動作成）
npm run setup:backend
```

#### 3. サービスを起動

```bash
# フロントエンドとバックエンドを同時起動（プロジェクトルートで実行）
npm run dev
```

**サービス URL：**
- フロントエンド：`http://localhost:3000`
- バックエンド API：`http://localhost:5001`

**個別起動：**

```bash
npm run backend   # バックエンドのみ
npm run frontend  # フロントエンドのみ
```

### 方法2：Docker デプロイ

```bash
# 1. 環境変数を設定（ソースコードデプロイと同じ）
cp .env.example .env

# 2. イメージを取得して起動
docker compose up -d
```

デフォルトでルートの `.env` を読み込み、`3000（frontend）/5001（backend）` を公開します。

> 高速プル用のミラーアドレスは `docker-compose.yml` のコメントを参照し、必要に応じて置き換えてください。
